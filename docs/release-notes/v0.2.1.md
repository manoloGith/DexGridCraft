**DexGridCraft 0.2.1**

### Novedades
- **DexFiles** reconoce DexGridCraft como app Dex y la propone como aplicación predeterminada para las hojas de cálculo: xlsx, xlsm, xltx, xltm, xls, xlt, xlsb, ods, csv, tsv, tab, slk y scjson. Los archivos se abren con escritura de vuelta, como con «Abrir con».

### Instalar
`DexGridCraft-0.2.1-arm64-v8a.apk` (64 bits, Android 10 o posterior). Se actualiza sobre la 0.2.0; `SHA256SUMS.txt` sirve para comprobar la descarga.
